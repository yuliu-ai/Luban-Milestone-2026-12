# 演示控制台

[打开六通智能体演示控制台](https://liutong-luban-project.netlify.app/offline/)。入口已合并到项目页，首页点击演示控制台即可进入，返回项目页可继续查看架构、实验结果与应用场景。

控制台按跨任务、跨本体、跨环境选择案例，结合视频查看任务分解图、任务规划、原子技能输入输出、验证与恢复，以及独立的知识与经验区域。支持暂停、节点定位和播放速度调整。

视频与节点讲解用于演示，实际运行任务请按[安装](installation.zh-CN.md)、[配置](configuration.zh-CN.md)和[回合指南](episodes.zh-CN.md)准备资源。
