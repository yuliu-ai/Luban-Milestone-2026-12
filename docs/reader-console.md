# Demonstration console

[Open the Luban demonstration console](https://liutong-luban-project.netlify.app/offline/). The console is integrated into the project site. Enter from the project homepage and return to explore architecture, results and applications.

Select cases by task, embodiment or environment. Video is paired with task graphs, planning, atomic-skill inputs and outputs, verification, recovery, knowledge and experience. Playback supports pause, node selection and speed controls.

The console presents videos and node walkthroughs. To execute tasks, follow the [installation](installation.md), [configuration](configuration.md) and [episode guides](episodes.md).
