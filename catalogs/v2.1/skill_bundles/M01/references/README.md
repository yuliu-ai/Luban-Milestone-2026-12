# M01 · 参考资料

本目录只登记"设计这份契约时可以核对"的外部资料。本目录不存放模型权重、标定文件或设备配置；这些必须由部署时的 `verification_profile_ref` 与资源绑定提供。

| 来源 | 位置 | 在本技能中的用途 |

## 边界提醒

- 本技能的主要效果：以绝对目标或相对位移完成一次末端直线运动并约束横向偏差；撤离是本参数化的一次相对位移，不含恢复规划与绕障。
- 不包含：全局规划、跨阶段任务编排、无限等待、自动失败重试
