# P01 · 参考资料

本目录只登记"设计这份契约时可以核对"的外部资料，并标注来源与用途。本目录不存放模型权重、标定文件或设备配置；这些必须由部署时的 `verification_profile_ref` 与资源绑定提供。

## 已登记来源

| 来源 | 位置 | 在本技能中的用途 |
|---|---|---|
| 契约定义 | `../../atomic_skills.json` 的 `P01` 条目 | 唯一事实来源。与本文档冲突时以契约为准。 |
| ROS REP-103 标准单位与坐标约定 | `https://www.ros.org/reps/rep-0103.html`（登记于契约 `metadata.design_references` 的 R3） | `frame_id` 的右手系、单位与姿态表达约定 |

## 待补（绑定后端前必须完成）

- [ ] 检测模型及其版本标识（对应 `outputs.model_version`）
- [ ] 类别表：`class_filter` 的合法取值域，以及开放词表场景的处理方式
- [ ] `profile://detector/...` 验证配置：召回与精度阈值、NMS 参数、证据采集方式与保存周期
- [ ] 相机内参与 `frame_id` 对应的变换树
- [ ] 失败码 `LOW_CONFIDENCE` 与 `SENSOR_STALE` 的实际判定阈值

## 边界提醒

- 本技能只产出检测框，不做实例掩码（P02）、不做三维位姿（P03）、不做跨帧跟踪（P05）。
- `score_threshold` 是调用输入，属于"本次请求的目标"；验证配置中的阈值属于"判定规则"，两者不得互相替代。
