## 边界提醒

- 本技能的主要效果：只读返回一个同步窗口内的机器人状态快照（机械臂、底盘或飞行状态）；不发送任何控制命令。
- 不包含：全局规划、跨阶段任务编排、无限等待、自动失败重试
