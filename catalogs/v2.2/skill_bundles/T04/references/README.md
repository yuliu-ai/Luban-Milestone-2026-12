# T04 · 参考资料

本目录只登记"设计这份契约时可以核对"的外部资料，并标注来源与用途。本目录不存放力控参数、清洁度模型或工具标定；这些必须由 `verification_profile_ref` 与资源绑定提供。

## 已登记来源

| 来源 | 位置 | 在本技能中的用途 |
|---|---|---|
| 契约定义 | `../../atomic_skills.json` 的 `T04` 条目 | 唯一事实来源。`path_xy` 的二维点序列定义、力限与效果门槛均以契约为准。 |
| ROS REP-103 标准单位与坐标约定 | `https://www.ros.org/reps/rep-0103.html`（登记于契约 `metadata.design_references` 的 R3） | `surface_frame` 与 `path_xy` 的单位、平面方向约定 |
| v1 缺陷记录 | `../../legacy_retired_definitions.json` 与迁移账本 | v1 曾把 `path_xy` 的点定义为 7 维位姿数组，V2.1 已改为 2 元数组并在校验器与 few-shot 负例中阻断 |

## 待补（绑定后端前必须完成）

- [ ] 力控后端：法向力的来源（力矩传感器 / 关节估计 / 被动柔顺）与控制带宽
- [ ] 清洁度测量方式：`cleanliness_delta` 的传感器、单位与可重复性
- [ ] `profile://wipe/...` 验证配置：轨迹完成判定、效果阈值、峰值力上限、证据形式
- [ ] 工具附着估计器与 `tool_attachment_preserved` 的判定方法
- [ ] 表面模型（`surface_id` 对应的几何与摩擦信息）

## 边界提醒

- 单次行程不代表区域清洁：覆盖整片表面应由上层生成多条行程并逐次调用，不要在一个原子调用里做覆盖规划。
- 与 T07（刮取）的区别是材料移除方式与损伤判据不同，不能互相替代。
- 与 I08（落座）的区别是：本技能保持工具接触并产生清洁效果，不负责把物体放到支撑面。
